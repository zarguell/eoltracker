How to read these dates

The milestone meanings below are the catalog's shared vocabulary. The endoflife.date label rules do not apply to this record: stated dates come from the quoted vendor notices, while any derived date carries its own explicit vendor rule, base, source, and calculation.

General availability

First public release. Taken from the upstream releaseDate.

End of sale

Last day new licenses or units are sold. Only mapped from an upstream field whose label names an end of sale.

End of security support

Last day security fixes are published. Mapped from eolFrom or eoesFrom only when the label names security support.

End of life

End of all support. A published extended-support date wins; otherwise eolFrom when its label describes a full support end.

Blank date

The quoted notice publishes no value for that milestone. A missing date is an absent announcement, not a claim that support ends or continues.

Derived date

A date marked derived is computed from a rule the vendor states — an explicit duration, a release trigger, or a parent platform's lifecycle — applied to a published base date, never from release cadence. The method, base date, quote and source are printed in the derived dates block, so the date can be recomputed. It is excluded from the upcoming-deadlines list, the day-precision feeds and the OpenEoX export, each with its reason published.

Derived dates

These milestones are not dates the vendor states. Each one is computed from a rule the vendor does state — an explicit support duration, the release that ends the line, or a parent platform whose lifecycle this product follows — applied to a base date that is also published. The base, the rule and the sentence it came from are quoted below, so every date here can be recomputed and checked rather than taken on trust. They are labelled derived everywhere they appear, they are kept out of the upcoming-deadlines list above, and they are excluded from the day-precision feeds and the OpenEoX export, both of which carry only days a source states.
