Verbatim quote from the source

A final patch version is published when support is dropped, and that release also documents the end of support for that major version series. With the release of a new major version, the previous major version is supported for at least six months with only bug fixes, and one year for security fixes. The minimum period between major version releases is one year. The 0.46.0 release is the final minor version release for the 0.x series. The 0.46.x release series will continue to be supported and recieve bugfix and security fixes via patch releases for 6 months after this release. Qiskit 0.46.3 is a minor bugfix and backport release for the 0.46 series. It is also the last release of the 0.46 minor version, marking its end-of-life. the 0.46.x release will continue to be supported, with periodic patch releases that contain bug fixes, for 6 months after the release of 1.0. That is, 0.46.x will be supported until 2024-08. The v1.4.x release series will continue to be supported and receive bugfixes for 6 months and security fixes for 1 year after this release. Qiskit v1.4.5 is the last bugfix release in the 1.4 series and marks the end-of-life of the series. Support for security fixes in the 1.4 series will be continued until March 31st, 2026. Qiskit v1.4.6 is a security-only release, and the final release in the Qiskit v1.x series. Qiskit v1.x is no longer maintained in any form. The removed APIs are still supported in the Qiskit v1.4.x release which will receive bug fixes for another six months and will have security updates for one year. There will be further feature releases of Qiskit in the 2.x series; we do not expect to release Qiskit 3.0 until much later in 2026, as there is currently no need for breaking changes. An open-source SDK for working with quantum computers at the level of extended quantum circuits, operators, and primitives. This library is the core component of Qiskit, which contains the building blocks for creating and working with quantum circuits, quantum operators, and primitive functions (Sampler and Estimator). How to read these dates

The milestone meanings below are the catalog's shared vocabulary. The endoflife.date label rules do not apply to this record: stated dates come from the quoted vendor notices, while any derived date carries its own explicit vendor rule, base, source, and calculation.

General availability

First public release. Taken from the upstream releaseDate.

End of sale

Last day new licenses or units are sold. Only mapped from an upstream field whose label names an end of sale.

End of security support

Last day security fixes are published. Mapped from eolFrom or eoesFrom only when the label names security support.

End of life

End of all support. A published extended-support date wins; otherwise eolFrom when its label describes a full support end.

Blank date

The quoted notice publishes no value for that milestone. A missing date is an absent announcement, not a claim that support ends or continues.
