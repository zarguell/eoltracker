How to read these dates

General availability

First public release. Taken from the upstream releaseDate.

End of sale

Last day new licenses or units are sold. Only mapped from an upstream field whose label names an end of sale.

End of security support

Last day security fixes are published. Mapped from eolFrom or eoesFrom only when the label names security support.

Extended support counts as security support: when upstream publishes an extended-support date, it replaces the standard security-support deadline here.

End of life

End of all support. A published extended-support date wins; otherwise eolFrom when its label describes a full support end.

An announced extended-support period with no published end date leaves end of life blank — the earlier eolFrom value stays visible in the table rather than being promoted into a deadline upstream never set.

Blank date

The source publishes no value for that milestone. A missing date is an absent announcement, not a claim that support ends or continues.
