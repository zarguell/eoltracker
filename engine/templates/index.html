Machine-readable catalog

Both catalogs are published as JSON for offline use and tooling. Every record keeps the raw upstream values alongside the normalized dates, so consumers can re-derive or dispute the mapping.

  • v1/feed.jsonFull normalized software catalog: every field, every release, one versioned document.
  • v1/products.jsonSoftware summaries with counts and the absolute URL of each product endpoint.
  • v1/hardware.jsonHardware summaries: vendor, status, milestone coverage and the absolute URL of each record's endpoint.
  • v1/schema/product.jsonJSON Schema for a single software product record.
  • v1/schema/hardware.jsonJSON Schema for a single hardware record — one model or product group.
