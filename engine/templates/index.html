These {{ hardware_count }} records are also the whole hardware catalog: the dedicated hardware page carries the same rows with vendor, status and catalog-state grouping, the milestone coverage and the import report behind it, and v1/hardware.json carries one summary per record. A record is one published source row: for Opengear, either a lifecycle row whose part numbers are grouped rather than listed separately, or one exact model string the vendor's product catalogue lists. Record counts are not device or SKU counts.

Machine-readable catalog

Both catalogs are published as JSON for offline use and tooling. Every record keeps the raw upstream values alongside the normalized dates, so consumers can re-derive or dispute the mapping.

  • v1/feed.jsonFull normalized software catalog: every field, every release, one versioned document.
  • v1/feed.atomUpcoming deadlines as an Atom feed, with v1/feed.rss and v1/calendar.ics alongside it. Month-precision deadlines have no day for these formats and are enumerated in v1/feed-exclusions.json instead.
  • v1/products.jsonSoftware summaries with counts and the absolute URL of each product endpoint.
  • v1/hardware.jsonHardware summaries: vendor, status, catalog state, milestone coverage and the absolute URL of each record's endpoint.
